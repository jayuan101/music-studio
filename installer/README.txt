Music Studio - Installer
========================

To install on another computer:
  1. Copy this whole MusicStudio-Installer folder to the other PC
     (USB drive, network share, etc.).
  2. Double-click Install.cmd.

The app is installed into %LOCALAPPDATA%\Programs\MusicStudio and adds a
shortcut to the Start Menu and the Desktop. It does not need admin rights.
ffmpeg is included, so there's nothing else to install.

Updates: in the app, open Preferences > Updates and click "Check for
updates". If a newer version is available, click "Update now" to
download it and restart into the new version. This needs an internet
connection. You don't need to run the installer again.

To remove it, go to Settings > Apps > Music Studio > Uninstall, or
double-click Uninstall.cmd. Your settings and music files are kept.

If you'd rather not install it, you can run app\MusicStudio.exe directly.
